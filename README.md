# Rainfall Pattern Analysis & Planting Advisory

## Project Summary
This project cleans manually entered monthly rainfall station data for Machakos County, combines it with historical rainfall records across five Kenyan counties into a 5 × 12 NumPy array, and generates agricultural metrics (annual totals, wettest months, dry-month counts, and optimal two-month planting windows) exported to `rainfall_summary.csv`.
